## 🚀 Cómo correr

1. Requisitos: Node.js
2. Instala dependencias:
   ```bash
   npm install
   ```
3. Arranca el servidor:
   ```bash
   npm run dev
   ```
4. Abre en el navegador:
   - http://localhost:3000/

> Opcional: Si quieres usar Gemini, coloca tu clave en `.env.local` con `GEMINI_API_KEY=...`  
> (el modo IA en esta app funciona offline con mensajes especiales para Aranza).
